A terminal ellipsis (…) or three or more periods (... / ....) marks an incomplete ending. Such lines are recorded as truncated and are excluded from end-rhyme pairing, since their true final word is missing. Blank stanzas are analyzed separately; texts without stanza breaks are grouped into four-line sections.

Where is my data saved?

By default, dictionaries are saved only in this browser’s local storage; they are not sent to GitHub or a server. Use Export JSON to keep a backup and Import JSON on another browser. GitHub saving would require a separate authenticated integration (such as a GitHub App or OAuth flow); never put a personal access token in this static page.
